Give it a transcript and a range. It blows out every variant. 💨 전사체와 구간만 주세요. 가능한 변이를 전부 뿜어냅니다. 💨

VCFART reads HGVS ranges such as c.5075-100_c.5152+100, follows the transcript on your hg19 or hg38 FASTA, and writes every SNV, indel or codon swap as a sorted, normalized VCF that SpliceAI, ANNOVAR and VEP take as is.

VCFART는 c.5075-100_c.5152+100 같은 HGVS 구간을 읽고, hg19·hg38 FASTA 위에서 전사체를 따라가며, 가능한 모든 SNV·indel·코돈 치환을 정렬·정규화된 VCF로 씁니다. SpliceAI, ANNOVAR, VEP에 그대로 넣으면 됩니다.

python -m pip install vcfart

🧪Four ways to mutate변이를 만드는 네 가지 방법

Combine them in one run, for example -m snv,del,codon. Variants that are the same at the sequence level are written once.한 번에 섞어 쓸 수 있습니다(예: -m snv,del,codon). 서열상 같은 변이는 한 번만 기록됩니다.

-m snv
All three alternative bases at every position. This is the default.모든 위치에서 나머지 염기 3개로 치환합니다. 기본값입니다.
-m del --del-sizes 1,3
Deletions of the lengths you list. Deleting any C of a CCCCCC run gives one record, named by the 3′ rule.지정한 길이의 결실. CCCCCC 중 어느 C를 지워도 한 줄로 합쳐지고, 3′ rule로 이름 붙습니다.
-m ins --ins-sizes 1
Every k-mer inserted between every pair of bases. Insertions that copy the neighbouring sequence are reported as dup.모든 염기 사이에 가능한 모든 k-mer 삽입. 옆 서열을 복제하는 삽입은 dup으로 표기됩니다.
-m codon
Deep-mutational-scanning codon swaps: one codon per amino acid plus Ter and a synonymous control, all 63 codons, or NNK.DMS 방식 코돈 치환: 아미노산마다 코돈 하나 + Ter + 동의 코돈 대조군, 63개 전부, 또는 NNK.

🚀Start in four commands명령 네 개로 시작하기

Python 3.9 or newer, nothing else to install. Your FASTA gets a .fai index on first use if it has none.Python 3.9 이상이면 끝, 다른 설치는 없습니다. FASTA에 .fai가 없으면 처음 실행할 때 만듭니다.

  1. Install설치

    python -m pip install vcfart

  2. Look up the transcript전사체 확인

    vcfart info -f hg38.fa -a humandb/hg38_refGene.txt -t NM_007294.4

  3. Generate the variants변이 생성

    vcfart generate -f hg38.fa -a humandb/hg38_refGene.txt -t NM_007294.4 \
    -r exon17:100 -m snv,del -o BRCA1_ex17

  4. Score them점수 매기기

    spliceai -I BRCA1_ex17.vcf -O BRCA1_ex17.spliceai.vcf -R hg38.fa -A grch38
